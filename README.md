# Weather Condition Selector 🌦️

## About the Project
Weather Condition Selector is a beginner-friendly front-end web development project built using HTML, CSS, and JavaScript.

Users can select a weather condition from a dropdown menu and see its matching emoji, title, description, and background colour.

## Features
- Six weather conditions: Sunny, Rainy, Cloudy, Snowy, Stormy, and Windy.
- Dynamic icons and descriptions.
- Background changes according to the selected condition.
- Default welcome message.
- Responsive design for mobile and desktop.
- No API required.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Make sure all three code files are in the same folder.
4. Open `index.html` in your browser or use the Live Server extension.
5. Select a weather condition from the dropdown.

## How It Works
HTML creates the dropdown and display area. CSS styles the webpage and provides different backgrounds. JavaScript uses an object to store weather details and updates the display when the selection changes.

## Learning Outcomes
- DOM manipulation
- JavaScript objects
- Event handling
- Conditional rendering
- Responsive CSS design

## Limitation
This is a demonstration project. It does not display real-time weather information.
